# PinkSlips

PinkSlips is a car build tracker and car mod tracker for project cars, motorcycles, and motorsports builds.

Owners can create one permanent build page for their specifications, modifications, wheels and tires, photos, videos, performance figures, milestones, shops, clubs, and complete build history.

[Visit PinkSlips](https://pinkslips.app) · [Explore builds](https://pinkslips.app/browse) · [Trust Center](https://pinkslips.app/trust)

## What we build

- Structured build pages with complete modification and specification records
- Photo and video galleries with modification tagging
- Wheels, tires, fitment, power, weight, and dyno documentation
- Milestones, trophies, build history, rankings, clubs, shops, routes, and events
- Web, iOS, and Android experiences for automotive enthusiasts

## Technology

PinkSlips is built with:

- **Web:** TypeScript, React, Vite, TanStack Query, Tailwind CSS, and Radix UI
- **API:** Node.js, Express, TypeScript, and Drizzle ORM
- **Data:** PostgreSQL on Neon
- **Mobile:** Capacitor with native iOS and Android integrations
- **Infrastructure:** Vercel, Railway, Cloudflare, and Cloudflare R2
- **Reliability:** Sentry error and performance monitoring
- **Product analytics:** PostHog and Google Analytics
- **Identity and payments:** Google, Apple, and Stripe

## Security and privacy

PinkSlips uses server-side public-data filtering, protected production sessions, ownership checks for private records, API rate limits, input validation, upload restrictions, and role-based authorization.

Using PinkSlips does not require GitHub. Regular product feedback and support remain available through the app and by email.
